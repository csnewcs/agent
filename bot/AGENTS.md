# ai agent bot

이 프로젝트는 개인 사용자의 AI Agent의 진입점인 Discord Bot을 구현한 것입니다. 이 봇의 기능은 다음과 같습니다.

해당 AI Agent는 n8n을 사용합니다.

1. 지정한 채널의 대화 내역을 DB에 저장합니다.
2. 사용자는 AI에게 슬래시 커맨드 혹은 멘션의 형태로 질문을 할 수 있습니다.

채팅 내역은 DB에 저장되며, localhost:5432에서 실행되는 postgresql을 사용합니다. DB 이름은 agent, 사용자 이름은 agent이며 비밀번호 인증은 하지 않습니다.

저장되는 채팅은 다음과 같은 정보를 포함합니다.
- 사용자 ID
- 내용
- 이미지, 파일 포함 여부
- (이미지나 파일이 포함되어있다면) 해당 파일의 URL
- 전송 시각

단 채팅을 저장하고 가장 최근의 30개의 채팅만 유지하며, 그 이전의 채팅은 DB에서 삭제합니다.

---

사용자가 해당 봇을 멘션하거나 슬래시 커맨드를 사용하면 봇은 n8n의 webhook을 호출하여 AI Agent에게 질문을 전달합니다.

엔드포인트는 다음과 같습니다 "http://localhost:5678/webhook-test/discord". 해당 webhook을 전송할 때 위에서 저장한 DB의 모든 채팅 내역을 포함해야 합니다.
